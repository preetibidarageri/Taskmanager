# Task Manager

A full-stack **Task Manager** developed during my internship using Django, HTML, CSS, JavaScript, and MySQL.

## Features

* User authentication
* Create, view, update, and delete tasks
* Task status tracking
* Task management dashboard
* PDF upload
* PDF reading progress tracking
* Database integration
* Frontend and backend integration
* CRUD operations

## Technologies Used

* Python
* Django
* HTML
* CSS
* JavaScript
* MySQL

## Deployment

Deployed using **Render**.

**Live Demo:** https://taskmanager-j81y.onrender.com/
